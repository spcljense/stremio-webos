# Stremio webOS 1.1.3

## Startup and streaming
- Improved loading-screen handling, service-response parsing and startup polling.
- Added remote Back handling in the startup shell.
- Added local proxy connection reuse, backend startup retries and disconnect cleanup.
- Improved service startup error handling and shutdown cleanup.

## Subtitles and audio
- Added external subtitle redirect handling, gzip/deflate decoding and size limits.
- Improved multiline subtitle parsing, including dialogue separated by blank lines.
- Extended abnormally short subtitle cues.
- Added audio-language normalization and commentary filtering in the modified automatic-selection path.
- Changed media-probe failures to use the existing transcoding decision path.
- Added CSS suppression of duplicate native subtitle text.

## Profiles and browsing
- Skip the startup profile picker when there is one unprotected profile.
- Preserve profile selection for multiple profiles and PIN-protected profiles.
- Changed Library grouping and focus calculations to six items per row.
- Added matching poster-sizing rules.
- Made the existing Details action always visible.
- Adjusted source-card sizing and source-detail spacing.

## Skip Intro / Outro
- Down opens player controls instead of trapping focus on Skip.
- Prevented Skip from reappearing while a seek is pending.
- Added failed-seek feedback and retry handling.
- Retained native seek requests until video metadata is ready.
- Added regression tests and refreshed changed script URLs.

## Known limitation
The compact source-screen header styling uses CSS :has(), which is
unsupported on older webOS engines, including webOS 5.x. The complete
header redesign is not yet available on those models.

## Package
This release uses the exact locally built IPK successfully installed
on the developer's LG CX. The release asset was not rebuilt by CI.

Earlier Sickerine-derived functionality is retained but is not presented
as newly introduced in this release.
