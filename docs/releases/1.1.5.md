## Stremio webOS 1.1.5

This release expands skip-segment support, improves embedded subtitle rendering and cleans up the webOS interface while preserving the player-control and native-seek fixes introduced in 1.1.3.

### Skip segments

- Added read-only SkipDB lookup for intro, recap, outro and preview segments without an API key or Stremio Premium requirement.
- Added separate colored blocks to the seek bar: recap (yellow), intro (green), outro (coral) and preview (blue).
- Added a compact legend with the exact start and end time of every visible segment.
- Added support for movies, normal series episodes and season-zero anime specials when an IMDb ID is available.
- Stremio Core's existing intro/outro data remains preferred when available; SkipDB fills missing segment types.
- Unsafe out-of-range duration matches are ignored.
- SkipDB/API failures never prevent playback or Stremio's built-in segment data from working.
- Down still escapes the skip popup and focuses the player timeline without pausing or seeking.
- OK still hides the popup immediately, prevents repeated seeks while pending and retains the existing retry timeout.
- Official intro/outro skips retain the delayed native-seek protection introduced in 1.1.3.

### Subtitles

- Added the Nuvio-style HTML renderer for embedded subtitles.
- Added outlined subtitle rendering for improved readability.
- Native webOS subtitle rendering is suppressed while the HTML embedded-subtitle renderer is active.
- External/native subtitle behavior remains available outside the embedded HTML renderer.
- Added UTF-8/Windows-1252 mojibake repair for proxied VTT subtitles.

### Interface

- Disabled animations and background blur for a lighter webOS interface.
- Removed the blurred details-page background effect.
- Removed the Animations, Background Blur, 720p Mode, Playback Diagnostics and Apply Safe Playback Mode settings.
- Increased the focused profile avatar to 130%.
- Kept the sidebar avatar at its normal size.
- Removed the right-side navigation gradient/shadow.
