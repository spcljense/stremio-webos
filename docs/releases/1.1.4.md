## Stremio webOS 1.1.4

This hotfix restores embedded subtitle discovery on LG webOS.

### Fixed

- Restored embedded subtitles in the subtitle selection list.
- Prevented normal `/tracks` requests from being aborted before FFprobe finishes.
- Replaced the incorrect request `close` handler with the `aborted` handler.
- Preserved the subtitle parsing, Skip Intro and native seek fixes from version 1.1.3.
